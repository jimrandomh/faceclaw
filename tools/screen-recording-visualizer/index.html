Screen recording

Open a Faceclaw screen recording

Drop a recording-….fcrec.jsonl file anywhere on this page, or use Open recording….

  1. In the phone app, choose Record screen from the menu, use the glasses, then tap Stop recording.
  2. Fetch the file with scripts/pull-screen-recording.sh.
  3. Open it here. Nothing is uploaded: the page reads the file locally.

Click or drag to move the playhead · scroll to zoom · shift-scroll to pan · double-click to fit the whole recording. The Frames, Messages and Bandwidth tabs list the same data as tables.
